# 板书对齐工作台 0.4.1

把无声板书视频对齐到一条固定旁白：先用录音转写与板书 OCR 自动粗调，再在双轨时间线上人工配对、拖动锚点、裁剪和定格。成片重新编码画面，AAC 旁白按包复制并自动核验；字幕始终使用旁白时间。

这是本地应用源码，建议使用 Windows 10/11、完整 Python 3.12、近期 Chrome/Edge。手工编辑只依赖 Python 标准库；兼容预览和导出需另装 FFmpeg。自动粗调需要额外的本地分析依赖和模型。不是免安装 EXE。

## 首次运行

1. 安装完整 Python 3.12（含 Tcl/Tk）和 FFmpeg，将源码 ZIP 完整解压到可写目录。
2. 在源码根目录运行 `.\run.cmd`，保留启动终端。
3. 人工路线：先选板书视频和旁白，再点“导入 CSV”。自动路线：按[中文手册](docs/USER_GUIDE.zh-CN.md)准备分析环境，再点“开始 / 重新粗调”。
4. 核对候选、细调、保存 `.align.json`，导出成片并确认 AAC 校验通过。

```powershell
py -3.12 app.py --ffmpeg "D:\Tools\ffmpeg\bin\ffmpeg.exe"
```

文档中的 `D:\Tools`、`D:\Media` 是示例，请替换为自己的路径。

## 数据与限制

应用在本机分析，不把媒体或课程文本发送到云端；安装依赖和首次下载模型需要网络。素材、OCR、字幕、项目和日志可能含隐私，请勿公开提交。

自动粗调是待核对的建议，不保证逐句正确；内容支撑覆盖不是对齐准确率。AAC 原始流一致性闭环要求 AAC/M4A 输入。其他限制见手册。
