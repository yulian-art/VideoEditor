# 板书对齐工作台 0.4.1

本地板书视频与固定旁白对齐工作台。提供 CSV 导入、60/20 秒自动粗调、真实源帧核对、双轨人工细调、独立裁剪和定格、项目保存恢复，以及带 AAC 原包校验的 MP4 导出。

## 本版修复

- 语义缓存使用 v2 身份，包含 worker/算法实现摘要、模型/分词器摘要及影响向量的运行时和执行环境信息。旧 v1 缓存明确失效，不迁移为可信新结果。
- INT8 嵌入逐条文本推理，消除同批文本集合变化导致的缓存向量差异，支持同身份冷/热复算。
- 候选和待核对项按保存的源时间直接显示真实板书帧；核对投影与缺板书提示区分未知定位和已匹配内容。
- 独立裁剪保存自动/人工暂存点，保护锁定点，预览与导出共用 source 跳变映射。

## GitHub 发行整理

补齐中文使用手册、合成演示生成器、四类实际导出/AAC 检查、显式文件打包与隐私审计、固定换行和基础 CI。已验收核心实现摘要保存在 `docs/RUNTIME_IDENTITY.json`。

源码和 demo 不含私人课程媒体、ASR/OCR、人工参考表、缓存或历史失效证据。实际课程的匹配质量不能从合成演示推断，需按自己的参考表独立评估。

## 下载和使用

完整解压源码 ZIP，按中文手册安装完整 Python 3.12、FFmpeg；自动粗调另需本地依赖和模型。演示 ZIP 可单独解压后打开其中项目。不是免安装程序，不捆绑 FFmpeg 或模型。

请核对 `SHA256SUMS`，ZIP 内附逐文件 `MANIFEST.sha256`。音频保持保证以原 AAC/M4A 与导出成片的包内容、数量、时间戳一致性校验通过为准。

## 升级提示与限制

保存旧项目副本后升级。首次分析取消“仅使用缓存”，让当前实现生成 v2 缓存；旧缓存保留但不复用。跨模型、运行时或硬件需要重新计算。

粗调是候选建议，未知/缺板书区间仍需人工处理，覆盖不等于准确率。字幕旁挂 SRT；当前音频闭环针对 AAC/M4A，不提供 WAV/MP3 原包保证或任意旁白变速。兼容预览可能低帧率，精调后核对输出。
